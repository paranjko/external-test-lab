Native CLI · 1.0.0-alpha.1

gonkactl

A CLI for Gonka stands and nodes.
The first step toward native deployment control.

Install the alpha

curl -LsSf https://gonka-dev.net/ctl/install.sh | sh

Linux & macOS · SHA-256 verified · Installs to ~/.local/bin

Prefer to inspect first? Read the installer.

An early distribution preview. This alpha exposes help, version information and shell completion. Host JOIN, reset, recovery and deployment commands are not available yet. Continue using the deployment runbook for node operations.

What you can run today

gonkactl --help
Explore the available commands and flags.
gonkactl version
Check the release, source commit and build date.
gonkactl completion bash
Generate completion for Bash, Zsh, Fish or PowerShell.
