COMPONENT TESTING / 1.0.0-beta.1

gonkactl-test

Run the test.
Keep the evidence.

A command-line tool for Gonka component E2E tests and test-run analysis. Validate the environment, run a fixture, and inspect what happened.

Install in one command

curl -LsSf https://gonka-dev.net/test/install.sh | sh

Installs to ~/.local/bin and verifies SHA-256 before installation. Read the installer.

Run locally

Launch an owned fixture with explicit inputs and cleanup receipts.

Use a test stand

Run profile-bound qualification on the stand host with an exclusive fixture lease.

Validate first

Check environment profiles and composition digests before launch.

Inspect results

Parse test events, retain JSON evidence, and render Allure reports.

Start here

gonkactl-test --version
gonkactl-test --help
gonkactl-test setup-report
gonkactl-test run --help

HTML reports require Node.js 24–26 and npm. DevShard release fixtures also require Docker with Compose, Go 1.27, Git, Bash and reviewed feature inputs. This beta includes DevShard v5 bindings; unsupported scenarios are reported as not run.
