How to Join node

git clone https://github.com/paranjko/external-test-lab.git
alias gdc="$PWD/external-test-lab/net-deployment-runbook/gdc.sh"
gdc host join --public-host <IP_or_DOMAIN> <ssh-alias>
Minimum Host requirements For more details, read Community DevNet runbook/JOIN: add a Host
OS
Ubuntu 22.04, 24.04, or 26.04 (amd64)
GPU
NVIDIA GPU with 16 GB VRAM
Driver
NVIDIA R580 or newer
CUDA
GPU works in a CUDA 12.8 Docker container
CPU
8 threads or more (practical baseline)
Memory
32 GB RAM or more (practical baseline)
Storage
50 GiB free required, with 100–150 GB NVMe recommended
Network
Stable internet with a stable public IPv4 address or a DNS name that resolves to it
Ingress
TCP 80, 443, 5000, and the configured SSH port, plus UDP 443
Uptime
Always on with sleep and address changes disabled

Community DevNet currently runs Qwen/Qwen3-0.6B, its on-chain model profile declares v_ram: 16, check the live model registry, gdc does not accept a GPU from the VRAM number alone: qualification loads the model, checks /v1/models, completes an inference request, and records VRAM evidence, an 8 GB RTX 3070 may run this small model experimentally, but it is below the declared 16 GB and is not a guaranteed supported configuration
