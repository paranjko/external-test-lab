# QA / Infrastructure Testing Engineer

**Project:** External Test Lab & Community DevNet for the [Gonka](https://gonka.ai) decentralized AI inference network
**Engagement:** contract, 4-month pilot (extension subject to a new governance decision)
**Location:** remote
**Positions:** 2
**Compensation:** up to $4,000/month per engineer (public, community-approved budget — see [proposal](https://github.com/gonka-ai/gonka/discussions/1388))

## About the project

Gonka is a decentralized network for AI inference built on Cosmos SDK, with GPU hosts earning rewards through Proof of Compute. The community has funded an independent testing function: validating protocol upgrades, DevShard releases, and inference flows on a dedicated geographically distributed DevNet before they reach mainnet. All results are public — your test plans, reports, and defect write-ups will be visible to (and used by) the whole ecosystem.

## What you will do

- Contribute to quality standards and test strategy for the network
- Define acceptance criteria and test plans for core network lifecycle events and components
- Build pre-release validation frameworks: smoke checks and regression coverage for known failure patterns
- Deploy and verify distributed node and service stacks in production-like environments
- Validate critical cross-system flows end to end with documented evidence: participant and key flows, inference and proof-of-compute participation, gateway and proxy behavior
- Use health signals, chain queries, and logs as primary validation inputs
- Verify upgrade readiness, rollback feasibility, and post-change health across the stack
- Establish and document operational primitives (e.g. PoC validation threshold, inference validation threshold) based on DevNet experience; contribute findings to official Gonka documentation
- Support DevNet validation and release-readiness assessment before production rollouts
- Validate recovery and incident resolution through root-cause analysis and re-testing
- Report defects with clear reproduction steps, impact assessment, and release-blocking status
- Track quality metrics that reflect network health and operational reliability

## Required

- 3+ years in system QA / test engineering, SDET, or quality-focused DevOps/SRE
- Understanding of blockchain lifecycle, key and auth flows: registration, delegated permissions, fee grants
- Experience operating and validating blockchain nodes (Cosmos SDK preferred): sync, recovery, RPC queries, network phase behavior
- Experience validating distributed systems in production-like environments
- Strong test design: test plans, acceptance criteria, smoke/regression/e2e, edge cases, negative testing
- Solid Linux, SSH, shell scripting, and log-based verification
- Docker and container orchestration, including environment and config reload behavior
- Clear defect reporting and documentation: runbooks, test results, sign-off checklists
- Comfort with time-boxed validation before critical network events

## Nice to have

- SDET experience: scripted validation, CI pipelines, automated health checks
- Blockchain / Web3 QA: testnet operations, bridge testing, wallet/key flows, upgrade regression
- Cross-chain testing: EVM testnet validation, withdrawal flows, contract interaction
- GPU/ML inference testing: worker health, model serving, artifact delivery
- Experience with coordinated multi-node upgrades
- API gateway and proxy testing: failures, latency, request tracing
- Decentralized inference or Proof of Compute networks
